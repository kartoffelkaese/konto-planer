# Rechtstexte

Lege hier je Text eine Datei an – die Seite und die Verweise darauf erscheinen erst, wenn die
Datei existiert (danach neu bauen):

| Datei | Seite |
|-------|-------|
| `impressum.md` | `/impressum` |
| `datenschutz.md` | `/datenschutz` |
| `agb.md` | `/agb` |
| `widerruf.md` | `/widerruf` |

Die Dateien sind von der Versionsverwaltung ausgenommen, weil jede Installation eigene Texte hat.

Formatierung: Überschriften mit `#`, `##`, `###`; Aufzählungen mit `- `; Absätze durch eine
Leerzeile trennen. Internet- und E-Mail-Adressen werden automatisch anklickbar. HTML wird
nicht ausgewertet.
